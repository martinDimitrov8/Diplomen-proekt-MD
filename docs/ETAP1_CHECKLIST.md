# Предаване на Етап 1 — проверка преди изпращане

- [ ] Отворих и прегледах `Documentation_Stage1.docx` и актуализирах съдържанието в Word.
- [ ] Съгласувах структурата и текста с дипломния консултант и със задължителния училищен шаблон.
- [ ] Инсталирах .NET 8 SDK и Node.js LTS.
- [ ] Стартирах frontend прототипа с `npm install` и `npm run dev`.
- [ ] Настроих SQL Server и User Secrets за backend.
- [ ] Генерирах EF Core миграция `InitialCreate` и създадох локалната база данни.
- [ ] Проверих `dotnet build UrbanSignals.sln` и `dotnet test UrbanSignals.sln`.
- [ ] Създадох собствено GitHub хранилище и качих source code и документацията.
- [ ] Проверих, че repository няма пароли, локални настройки или лични данни.
- [ ] Предоставих на дипломния консултант достъп до GitHub и линк към документацията.
- [ ] Изпратих GitHub URL, линк към документацията и кратко описание на функционалностите.

**Важно:** този комплект не е качен автоматично в твоя GitHub или Google Drive. Направи собствено хранилище и качи файловете след като ги прегледаш.
